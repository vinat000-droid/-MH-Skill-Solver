# MHRSB Skill Solver FINAL

Monster Hunter Rise: Sunbreak向けブラウザ版スキルシミュレーター。

## 今回の変更
- GameWithのスキルシミュレーターの操作思想を参考に、目標スキルを全スキルから選択可能に変更。
- スキル名検索、カテゴリ絞り込み、Lv選択を追加。
- 属性攻撃強化は火・水・氷・雷・龍を個別選択。
- 弱点特効【属性】などCSV内の特殊表記を正規化。
- 武器種指定は行わない。
- 護石入力、武器スロット、MR/全防具、傀異錬成許容は従来版を維持。

## データ
Sunbreak Ver.16.0系のRiseSim公開CSVをブラウザから読み込みます。
