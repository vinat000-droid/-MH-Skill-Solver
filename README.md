# MHRSB Skill Solver FINAL

Monster Hunter Rise: Sunbreak (Ver.16.0系) のブラウザ版スキルソルバーです。

## 機能
- MR防具5部位の探索
- Sunbreak装飾品データの読み込み
- 2スキル装飾品を含む不足スキル充足探索
- 手持ち護石のスキル/スロット固定
- 武器スロット入力
- 目標スキルに対する傀異錬成候補の提示
- 傀異錬成で対象にできないスキル（伏魔響命など）を追加候補から除外
- 防具レア度による傀異錬成基礎コストの目安を表示

## データ
防具・装飾品・スキルは EXXXI/RiseSim の公開CSVをブラウザから取得します。RiseSimはSunbreak Ver.16.0系データに対応しています。

## 注意
この版は「完成形のブラウザUI＋合法候補探索」を優先しています。護石のランダム錬金結果そのものを全件生成する機能、傀異錬成の抽選テーブルを使った確率計算、移植順序の完全再現までは実装していません。錬成欄はゲーム内で抽選可能なスキルと既知のコストクラスを使って、必要条件を提示します。
