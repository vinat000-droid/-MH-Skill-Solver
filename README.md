# MHRSB Skill Solver FINAL v14

Sunbreak Ver.16系のスキルシミュレーター。今回の版では「スキル充足度＋スロット構成＋護石・錬成余地」を評価軸にし、護石錬金と防具の傀異錬成について、確認できた実在条件を候補生成に反映します。

## 今回の変更
- 傀異錬金術「覇気」で実在する護石スロット組み合わせだけを推薦。
- 護石は最大2スキル、スキル1/2の最大Lv差を反映。
- 伏魔響命・狂化など、傀異錬成では付かないスキルを錬成候補から除外。
- 防具の傀異錬成はスキルコストと防具基礎コストを評価し、基礎コスト不足時はマイナス補正が必要な候補として表示。
- 護石候補と錬成候補は、検証済み条件がないものを「合法」として生成しない保守的設計。
- 旧版の固定4-0-0等の架空護石候補を廃止。

## 注意
傀異錬成はランダム抽選であり、「合法に出現可能」と「狙った結果を必ず引ける」は別です。本版では出現可能性・コスト条件を評価し、確率そのものは評価していません。
